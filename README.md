# Emotion Detection Using NLP

# Project Description

Emotion Detection Using NLP is a Machine Learning project that identifies the emotion expressed in a text.

The project uses Natural Language Processing (NLP) techniques to preprocess text and Machine Learning algorithms to classify text into different emotion categories.

# Objective

The main objective of this project is to automatically detect emotions from text instead of manually analyzing large amounts of text.

# Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Natural Language Processing (NLP)
- TF-IDF
- Logistic Regression

# Dataset

The project uses the **Tweet Emotion Dataset**, which contains text data along with their corresponding emotion labels.

The dataset is used for training and testing the Machine Learning model.

# Project Workflow

1. Load the dataset
2. Explore the data
3. Clean and preprocess the text
4. Tokenize the text
5. Remove stop words
6. Perform text normalization
7. Convert text into numerical features using TF-IDF
8. Split the dataset into training and testing data
9. Train the Machine Learning model
10. Predict emotions
11. Evaluate the model

# Machine Learning Model

The project uses **Logistic Regression** for emotion classification.

TF-IDF (Term Frequency-Inverse Document Frequency) is used to convert text data into numerical features that can be provided to the Machine Learning model.

# Results

The model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Classification Report
