# Emotion Detection Using NLP

## Project Description

This project uses Natural Language Processing (NLP) and Machine Learning to detect emotions from text.

## Technologies Used

- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression
- Matplotlib
- Seaborn

## Dataset

Tweet Emotion Dataset

## Machine Learning Model

Logistic Regression

## Project Workflow

1. Data collection
2. Data preprocessing
3. Text cleaning
4. Tokenization
5. Stop-word removal
6. TF-IDF feature extraction
7. Model training
8. Model evaluation
